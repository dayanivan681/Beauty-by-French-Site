# Fotos del salón

Coloca aquí las fotos reales (JPG/WebP, ~1400px lado largo, <300 KB) y reemplaza las URLs de Unsplash en `index.html`.

Sugerido:
- `hero.jpg` — foto principal vertical (4:5)
- `salon-1.jpg`, `salon-2.jpg` — interior / estilista trabajando
- `trabajo-01.jpg` … `trabajo-08.jpg` — portafolio
- `french.jpg`, `equipo-*.jpg` — equipo (4:5)
- `ig-1.jpg` … `ig-6.jpg` — tira de Instagram (1:1)

Los datos del negocio (WhatsApp, Instagram, dirección, horario) se editan en `script.js` → `SITE`.
